
# 🏦 Simple Banking System
**Java console application simulating core bank account operations.**

Built by Damian Ciumacenco — Software Engineering student at Maynooth University.

---

## 📌 Overview
A Java OOP project that simulates a basic banking system through the terminal. The user creates an account, then can deposit, withdraw, check their balance and view a full transaction history — all within a clean menu-driven interface.

---

## ✨ Features
- Create a personalised bank account
- Deposit funds with validation
- Withdraw funds with insufficient balance protection
- Check current balance at any time
- View full transaction history with running balance
- Clean menu loop with exit handling

---

## 🛠️ Built With
- Java
- Object-Oriented Programming (Classes, Encapsulation)
- ArrayList for transaction history
- Scanner for user input

---

## 🚀 How to Run

**Requirements:** Java JDK installed

```bash
# Compile
javac BankAccount.java Main.java

# Run
java Main
```
